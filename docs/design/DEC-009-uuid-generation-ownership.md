# DEC-009: UUID Generation Ownership

## Status

Accepted for v0.1 contract baseline.

## Context

The migration plan previously allowed primary identifiers to be generated by either the application boundary or database defaults. That ambiguity would make Alembic scaffolding, repository contracts, fixtures, idempotency, and event-outbox ordering harder to verify.

## Decision

Stream Lite v0.1 shall use application-owned UUID generation for all externally visible identifiers before database insert. PostgreSQL columns shall use type `uuid` and `NOT NULL` constraints, but shall not rely on database UUID defaults for primary application identities in MVP migrations.

Application-owned IDs include:

- `watcher_id`
- `source_folder_id`
- `destination_folder_id`
- `file_id`
- `job_id`
- `history_id` / `transition_id`
- stage attempt IDs
- `retry_schedule_id`
- `command_id`
- `idempotency_key_id`
- `claim_id`
- `duplicate_observation_id`
- `quarantine_record_id`
- `outbox_id`
- `event_id`
- `event_offset_id`
- `log_summary_id`
- `health_observation_id`

`event_id` shall be generated in the same transaction boundary that creates the `event_outbox` row. `correlation_id` shall be generated at the API, watcher, or worker boundary when one is not already present.

## Rationale

Application-owned UUIDs allow API responses, event envelopes, job state history rows, idempotency keys, and outbox records to share identifiers before persistence side effects are committed. This simplifies Pydantic fixtures, repository tests, outbox construction, and rollback behavior.

## Consequences

- Alembic migrations shall not need `gen_random_uuid()` or other database UUID-generation extensions for MVP primary keys.
- Repository functions shall require ID values as explicit inputs or generate them at the service boundary before insert.
- Database constraints still enforce UUID type, uniqueness, and referential integrity.
- Future database-default UUID generation requires a new decision and migration compatibility note.

- Refines SL-JOB-002.
- Refines SL-DCT-008.
- Refines SL-DCT-023.
